# Provider logos

These provider marks are copied from the upstream projects so the UI uses the real agent identity instead of letter placeholders.

- `dsh.svg` — DeepSeek Harness desktop icon, from `deepseek-ai/deepseek-harness` (`apps/desktop/resources/icon.svg`), MIT licensed.
- `zcode.png` — ZCode desktop icon, from `zai-org/ZCode` (`packages/desktop/build/icons/128x128.png`), Apache-2.0 licensed.
- `codex.svg` — OpenAI logomark used for Codex, from `openai/openai-cookbook` (`examples/agents_sdk/deployment_manager/frontend/src/openai-logomark.svg`), MIT licensed.

The files are used locally by the renderer and are animated with CSS only; no remote image requests are made at runtime.
