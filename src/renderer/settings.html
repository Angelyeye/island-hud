集成

连接现有 DSH 与 ZCode，会话仍由客户端管理。

DeepSeek Harness 检查中…

模式先保存为待应用配置。“安装 / 修复”后才写入本项目的受管插件。每次操作保留备份及其他插件。
ZCode 检查中…
安装会把 Island HUD 的 hook 写入 ZCode 用户配置（~/.zcode/cli/config.json），写入前自动备份；只改动本集成添加的条目。需要本机安装 Node.js。审批卡片打开期间 ZCode 的原生命令会等待岛上决策。
Claude Code 检查中…
安装会把 Island HUD 的 hook 写入 Claude Code 用户配置（~/.claude/settings.json），写入前自动备份；只改动本集成添加的条目，已有的其他 hook（如通知、状态栏）保持不变。需要本机安装 Node.js。审批与 AskUserQuestion 问答卡片打开期间 Claude Code 会等待岛上决策；若检测到其他审批类 hook 会提示共存注意。
Codex 检查中…
安装会把 Island HUD 的 hook 写入 Codex 配置（~/.codex/hooks.json），写入前自动备份；只改动本集成添加的条目，其他工具写入的内容保持不变。需要本机安装 Node.js。安装后需在 Codex 内运行一次 /hooks 信任本集成；审批卡片仅在交互（TUI）会话出现——Codex 的 exec/Desktop 模式不派发审批 hook（上游已知限制）。会话状态与完成提醒不受此限制。
